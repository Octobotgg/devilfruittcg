# DevilFruit Design System

This file is the shortest useful source of truth for the active DevilFruit visual identity.

If a UI change clashes with this file, the change should be reconsidered before it ships.

## Design Goal

DevilFruit should feel like the One Piece TCG home base:

- warm
- premium
- trustworthy
- fan-made
- sharp, not corporate

It should not feel like a generic SaaS dashboard.

## Active Visual Identity

### Palette

- page background: `#faf7f2`
- parchment surfaces: `#f5efe3`
- primary dark navy: `#1b2838`
- secondary navy: `#243447`
- gold accent: `#d4a054`
- gold-dark label tone: `#b8863c`
- sunset CTA: `#d15b3a`
- ocean link/action: `#2d6a8f`
- text dark: `#2a2118`
- text mid: `#5a4e40`
- text light: `#8a7e70`

### Typography

- display headers: `Pirata One`
- body copy: `Crimson Pro`
- navigation, controls, labels, stats, tables: `DM Sans`

### Feel

- editorial over dashboard
- collectible over software-y
- warm contrast over cold glow
- One Piece voyage energy over abstract tech energy

## Deprecated Identity

The following are no longer the site identity and should not come back without an explicit rebrand decision:

- cool-blue dashboard styling
- glassmorphism / frosted panels
- generic analytics-card layouts as the default visual language
- empty dark hero shells with low-contrast white text
- copy that sounds like startup software instead of a real One Piece TCG home base

## UI Rules

- Prefer parchment and cream as the default canvas.
- Use navy for high-emphasis sections, headers, and contrast moments.
- Use gold for framing, active states, dividers, and collectible accents.
- Use sunset for primary CTA moments, not as a background default.
- Dense utility screens should still feel designed, not like untouched admin pages.
- Tables, filters, and tools can be functional, but they still need the active palette and typography.
- Avoid visual dead space that reads like a generic app shell.
- Avoid decorative clutter that feels fake or theme-park-like.

## Tone Rules

- Write like someone who actually cares about One Piece and the game.
- Keep copy tight. Every line should earn its place.
- Do not oversell weak data.
- Trust and clarity matter more than hype.
- Flavor should support credibility, not overpower it.

## Review Test

Before shipping UI work, ask:

1. Does this still look like DevilFruit?
2. Would this feel out of place next to the current live homepage and tool pages?
3. Did we accidentally reach for a SaaS default because it was faster?
4. Does the page feel like a real One Piece TCG product, not a themed admin panel?

If the answer is off on any of those, revise before shipping.
